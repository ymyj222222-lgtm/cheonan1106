# 풍요로운 세상 풍세면 — 인터랙티브 웹 프레젠테이션

PowerPoint 6장의 내용과 시각 구성을 기반으로 제작한 정적 HTML/CSS/JavaScript 사이트입니다.

## 바로 열기
`index.html`을 Chrome, Edge, Safari 등 브라우저에서 엽니다. 서버·DB·외부 JS/CSS 라이브러리가 필요하지 않습니다.

## GitHub Pages 배포
1. GitHub에서 공개(Public) 또는 Pages 지원 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `styles.css`, `script.js`, `assets/`를 저장소 **최상위**에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장합니다.
4. 배포 후 `https://사용자명.github.io/저장소명/`에서 열립니다.

상대 경로 `assets/...`를 사용해 프로젝트 저장소에서도 리소스가 작동합니다.

## 조작
- 상단 메뉴, 오른쪽 점, 아래 이전/다음 버튼
- 키보드 방향키 · PageUp/PageDown · Home/End · 스페이스바
- 마우스 스크롤 및 모바일 터치 스크롤
- 오른쪽 상단 전체 화면 버튼 / 원본 PPT 슬라이드 비교
- 왼쪽 아래 출처 및 안내 팝업

## 파일
- `index.html`: 6장 화면 및 데이터·콘텐츠
- `styles.css`: 테마, 반응형 배치 및 전환 효과
- `script.js`: 슬라이드 이동, 키보드 제어, 모달, 전체화면
- `assets/`: 원본 제공 이미지, 6개 캐릭터, 손하트 GIF, 원본 PPT 화면 6장

## 유의사항
- 원본 PPT에 포함된 인구·사업 내용만 옮겼으며, 통계·사업 진행 상황을 새롭게 검증하거나 수정하지 않았습니다. 대외 발표 전 최신 공식 자료와 대조하세요.
- 발전 방향은 확정된 행정계획이 아닌 제안사항입니다.
- 실제 손하트 GIF는 움직이는 이미지로 포함되어 있습니다.
